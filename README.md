**[Serverless AI SIEM + SOAR on AWS](https://github.com/penguin-domain/serverless-soar)**
Wazuh alerts go through EventBridge and SQS to a Lambda that asks Gemini for a verdict, blocks the attacker at the VPC Network ACL, and posts to Slack. It runs on AWS Free Tier. The README covers the three things that broke and how I fixed them.
